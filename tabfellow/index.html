Tabfellow: Team Live Templates

Sharing live templates means exporting and importing XML by hand. Tabfellow keeps them in the project: commit one file, and teammates who have it get them when they open a project the IDE trusts.

  • Commit them with the project. One small file in .livetemplates.
  • No duplicate set-up per teammate. They open the project and the group is there.
  • Stay current after a pull (license). The group updates within seconds, no reopening.

Free: share and load, no time limit. $12 once for updates after a pull, write-back and the check page; 30-day trial of everything.

How it works

Quick start.

1. Share (free)
Tools | Share Live Templates with Project… writes a group of your own to one file in .livetemplates. Commit it.

2. Open (free)
A teammate with Tabfellow opens the project, trusts it when the IDE asks, and types an abbreviation and Tab. Nothing loads in an untrusted project (Safe Mode).

3. Pull (license)
After a pull, branch switch, stash or rebase the groups update without reopening the project.

4. Edit in place (license)
Change a template and press OK, then choose Write to Project or Discard. Only that group's file changes.

5. Check (license)
Settings | Tools | Tabfellow lists clashing abbreviations and templates your IDE cannot expand, each with a link to the template.

Pictures for steps 3 to 5 used a test stand-in for the license.

What the IDE already does. File templates already travel with a project (Project scheme); Tabfellow does not touch them. For your own two machines, use Backup and Sync.

Limits

  • Every teammate needs Tabfellow installed. Custom groups only.
  • While two projects are open, a shared template expands in either window. With a group of the same name in both, the IDE offers both templates until you close one project.
  • Not covered: postfix templates, Rider's C# templates, several repositories.
