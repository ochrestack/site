Tabfellow quick start

Sharing a group of live templates with your team, and what the license adds. Back to the Tabfellow product page.

Install

Tabfellow is not on JetBrains Marketplace yet, so there is nothing to install today. Once it is, each teammate opens Settings | Plugins, searches for Tabfellow and installs it, then restarts the IDE if it asks. It needs an IntelliJ-based IDE from build 251 (2025.1). That route has not been run, because there is no listing; installing the plugin from a file was run in IntelliJ IDEA Community 2025.1 and IntelliJ IDEA 2026.3.

Share a group (you)

  1. In Settings | Editor | Live Templates keep your project's templates in one group of your own, not one of the IDE's.
  2. Choose Tools | Share Live Templates with Project… (also in Find Action, and in the context menu of the project root). Tick the group and press Share. It is written to .livetemplates/<group>.xml; a group that already has a file under .idea/liveTemplates is written there. If the file already holds templates your group lacks, Share asks: another file name (the default), merge, replace or skip.
  3. Commit the new file. The IDE asks whether to add it to Git.
  4. To make the IDE ask newcomers to install Tabfellow, press Open Required Plugins… in the share dialog, press +, choose Tabfellow: Team Live Templates in the Plugin box, press OK in both dialogs, and commit .idea/externalDependencies.xml.

Your own group stays as it is, so on your machine the IDE offers both your template and the shared one; delete your own group once the shared one has loaded if you want only one. Tools | Stop Sharing Live Templates… deletes one group's file after a confirmation that names it.

Teammates

  1. Install Tabfellow, open the project, and trust it if the IDE asks. The group is in Settings | Editor | Live Templates as group (project name). Type an abbreviation and press Tab.

Nothing loaded? The IDE opened the project in Safe Mode (the Project view shows [untrusted]): trust the project, or choose Tools | Reload Shared Live Templates. A template that calls groovyScript (a function that runs a script) loads switched off, and a notice says so; read it, then press Allow in the notice or on the Tabfellow page.

With a license

  • Follow the repository. After a pull, branch switch, stash, rebase or any change to the shared files outside the IDE, the groups update within seconds without reopening the project. One notification lists what changed; Turn off these notifications silences it.
  • Edit in place. Change, add or delete a template in a shared group and press OK. A notification offers Write to Project or Discard. A read-only file is not written, and the notification says why.
  • Check page. Settings | Tools | Tabfellow lists, per shared group, abbreviations that one of your own templates, one of the IDE's or another shared group also uses in a context both have on; templates for a language your IDE lacks; unknown functions in variables; scripts; and templates with no context. Each problem has a link that opens the template in Settings | Editor | Live Templates (not while that page holds unapplied edits).

License and trial

Sharing and loading are free with no time limit. Following, editing in place and the check page need a JetBrains Marketplace license: $12 once, the same for personal and commercial use, with a 30-day trial of everything. Nothing renews. When the trial ends Tabfellow shows no popup (checked with a test stand-in for the license); the Tabfellow page then says so in one line.

On the Tabfellow page, Start the 30-day trial or enter a license… opens the IDE's license dialog (titled Manage Licenses in 2025.1 and Manage Subscriptions in 2026.3) for Tabfellow. Its words, in plain terms:

  • No license. beside the plugin in Settings | Plugins: the IDE's wording when no paid license is held. The free part works.
  • Subscription: the IDE's word for a license kept in your JetBrains Account. Tabfellow has no subscription; it is a one-time purchase, a Perpetual License in Marketplace terms.
  • Log In to JetBrains Account: the trial and the license live in your account. Tabfellow never sees it.

The trial can start only once Tabfellow is on the Marketplace. In Android Studio, install the plugin JetBrains Marketplace Licensing first; the Tabfellow page names it and offers Open Settings | Plugins….

Limits

  • Every teammate needs Tabfellow installed to load the groups. Custom groups only; the IDE's predefined groups are not shared.
  • While two projects are open, a shared template can be expanded in either window.
  • Not covered: postfix templates, Rider's C# templates, several repositories or submodules at once, Remote Development and Code With Me clients.
  • Everything here was run on Linux. Windows and macOS desktops, a real Marketplace trial or purchase, and PhpStorm, WebStorm, PyCharm and GoLand (checked by Plugin Verifier and tests only) were not run (details).

Privacy

Tabfellow reads and writes live template files in the open project and the IDE's live template settings. It makes no network calls and sends nothing; the IDE's own license and update checks are the IDE's (privacy policy).
