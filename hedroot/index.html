Hedroot: Header/Source Folders

CLion's New | C++ Class writes both files into the folder you right-click, so with include/ and src/ you move the header by hand every time. Hedroot's dialog puts each file in its folder.

  • The header lands in include/, the source in src/, the #include right.
  • I see both paths before anything is written.
  • Each module gets its own folders, and my team shares the rules (license).

Free: one placement rule and the dialog, no time limit. $7 once adds a rule per module, CMake target lines, CLion's own New dialogs and shared rules; 30-day trial.

How it works

1. Set a rule (free)
A header folder and a source folder, here include/fmt and src for {fmt}.

2. Create a class (free)
New | C++ Class (Header/Source Folders), check the paths above. On {fmt}, CLion's own dialog puts formatter.h in src; Hedroot puts it in include/fmt with #include "fmt/formatter.h" (headless run).

3. With a license
The dialog names the CMake line it will change, or says why it will not. On {fmt} that is inside if (FMT_OS), so you choose the target.

The license also adds namespace subfolders, moving the files CLion's own dialogs make (a Move back link, off until you turn it on) and team rules in .hedroot-rules. $7 once, every update included; trial and details.
