Hexgrain: Debugger Hex View

In the IntelliJ IDEA debugger a byte[] is a column of signed decimals, 100 at a time, so Hexgrain shows it as a hex dump.

  • Read it like a hex editor: 8, 16 or 32 bytes a row, the characters beside them.
  • See what the last step changed: changed bytes are marked at every pause.
  • Big arrays, no drilling into indices: Go to offset, Find, a data inspector, Save (licence).

Free up to 64 KB, no time limit. $9 once for the rest.

In the IDE, for real

For a quick look, the IDE may be enough. View as > Hex shows each element in hex, one per row; View as > String shows one line of text; a Type Renderer you write can print hex. Memory View covers C, C++ and Rust; a free plugin shows some debugger values, including Java byte arrays, as binary.

Known limits

  • Not for Rider, Python, Go, JavaScript, C, C++, Rust, Remote Development or Android Studio.
  • Changes are marked anywhere in arrays up to 1 MiB; in larger ones, in the rows read at both pauses.
  • Read-only. A direct ByteBuffer is read through a copy in the program's heap.
  • Measured up to 1 GiB: first rows within 85 ms; a Find through all of it takes 38 to 53 seconds.
