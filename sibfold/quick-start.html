Sibfold quick start

Your first rule, and what the license adds. Back to the product page.

Install

Sibfold is not on JetBrains Marketplace yet, so there is nothing to install from there today.

Installing from a zip file was run in IntelliJ IDEA and PyCharm 2025.2 and 2026.3: Settings | Plugins, the gear menu, Install Plugin from Disk..., pick the zip without unpacking it, Accept the Third-Party Plugins Notice, then Restart IDE. After a restart the IDE may show its own “Cannot update plugins” balloon for a plugin installed from a file; it comes from the IDE and does not affect Sibfold.

After the restart the IDE shows no sign of Sibfold. It lives in three places: Settings | Appearance & Behavior | Sibfold; the Project view's options menu (the three dots in the Project tool window) | Appearance | Sibfold Nesting Rules...; and Find Action (Ctrl+Shift+A), typing “Sibfold Nesting Rules”.

Your first rule

  1. Open the settings page and click +.
  2. Give the rule a name, a Parent pattern such as (?<base>.+)\.go and a Child pattern such as ${base}(_.+)?_test\.go. Use your own extensions in place of .go and _test.go.
  3. Under the editor, Matches in the open project lists the parents and the files that would go under them, by folder, as you type. A pattern with an error is marked in its field with the character where it fails, and cannot be applied until it is fixed.
  4. Optional: type file names into Try file names, one per line, to see which would nest under which. Nothing on disk is touched.
  5. Click OK. The Project view folds the files. Open a nested file and run Select Opened File (Find Action) to find it under its parent.

Nothing nested? Open the options menu | Appearance and look at Sibfold Nesting: it is the one switch that hides all of Sibfold's work. If the rule list says “pattern error”, fix the pattern first.

With a license

Each of these needs a license or the 30-day trial.

  • More rules. Every enabled rule is in force, in list order. A file that two rules would claim goes to the first rule.
  • Share with the team. Save Rules to sibfold.rules writes your rules to the project root. Commit it; teammates who have Sibfold, and a license or the trial, get the rules, applied after their own. If the file already holds rules that are not among yours, the question names them and says saving removes them.
  • Levels. A child can hold children, up to 5 levels below the top file. A set of rules that would make a loop is refused, naming the files in it.
  • Ready Rule Sets... Choose a set; the dialog shows what it would nest in your project; Add Rules puts ordinary rules at the end of your list.

License and trial

One rule at a time, the tester, Select Opened File and live updates are free with no time limit. The license is $7 once, the same for personal and commercial use, with a 30-day trial of everything; nothing renews. When the trial ends nothing pops up: your first rule keeps working, the others stay saved and marked not in force, and the settings page says in one line what the license adds.

The license is checked through JetBrains Marketplace licensing, which is the IDE's own. The trial and the purchase can start only once Sibfold is on the Marketplace; they have not been run. Android Studio has no JetBrains licensing, so only the free tier would apply there (not run in Android Studio).

Pattern syntax

  • Java regular expressions, matched against the whole file name: (.+)\.go matches user.go, not user.go.bak.
  • Use the parent's groups in the child pattern by number ($1) or by name (${base}, from (?<base>...)). The text a group captured is used literally.
  • A $ not followed by a digit or { ends the name, as usual. Use \$ for a dollar sign. Flags such as (?i) work.
  • If several parents of one rule could take a file, the one with the longest name wins. A file never becomes its own child.

Limits

  • Files in the same folder only. The Project and Project Files views, not Scopes or Packages, and not Rider. Files are never moved, renamed or changed; the one file Sibfold writes is sibfold.rules.
  • A file the IDE's own File Nesting rules already put under a parent stays there.
  • Everything here was run on Linux. Windows and macOS desktops and a WebStorm window were not run (details).

Privacy

Sibfold reads the names of files in the open project and, when you use it, the rules file. It makes no network calls and sends nothing (privacy policy).
