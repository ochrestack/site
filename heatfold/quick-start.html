Heatfold quick start

Installing Heatfold, making a profile it can open, and reading it next to your code. Back to the Heatfold product page.

Install (IDEs on the 2025.3 platform or later)

  1. In the IDE, open Settings | Plugins | Marketplace, search for Heatfold and click Install. The listing is in review and not on JetBrains Marketplace yet; until it is live, the search finds nothing.
  2. Or, with the plugin zip on disk: Settings | Plugins | ⚙ | Install Plugin from Disk…, choose the zip, and accept the Third-Party Plugins notice.
  3. Restart the IDE when it asks.
  4. After the restart the IDE opens its own licence dialog with Heatfold under Paid Plugins. It opens on the Paid license tab; click the Start trial tab next to it for the 30-day trial, or activate your licence there. Starting the trial means logging in to a JetBrains Account; it is free, and the dialog's Register… link creates one. Help | Manage Subscriptions… opens the same dialog later.

If you closed the licence dialog: the IDE restarts "to disable features requiring license" and Heatfold is gone, with no tool window and no message. To bring it back, open Help | Manage Subscriptions…, choose Disabled Paid Plugins, tick Heatfold and click Enable selected plugins and restart. After the restart the licence dialog opens again.

Heatfold has been used in IntelliJ IDEA and PyCharm on Linux. In CLion and RustRover it was tested headless, not yet in a window. Windows, macOS and Remote Development have not been tested yet. JetBrains' Plugin Verifier reports it compatible with CLion, RustRover, PyCharm and IntelliJ IDEA 2025.3 and 2026.3.

1. Make a profile

Heatfold reads the file your profiler already writes. Run one of these on the machine that has the program:

  • gprof: gprof ./program gmon.out > report.txt, or gprof -l for line entries.
  • perf: perf script -i perf.data > profile.perf.txt; add -F +srcline for file and line.
  • pprof: a file from go test -cpuprofile cpu.pprof, runtime/pprof or pprof-rs.
  • Trace JSON: clang -ftime-trace, or py-spy record -f chrometrace -o trace.json -- python app.py.

perf.data and gmon.out themselves are not read: they need the profiled binary and its symbols. The text file that perf script or gprof writes opens anywhere.

2. Open it

  • Open the Heatfold tool window from the bottom tool window bar and click Open Profile…, or right-click the file in the Project view and choose Open in Heatfold.
  • The file name does not matter, and gzipped files open the same way. Each profile opens in its own tab.
  • A file Heatfold cannot read shows the four formats and the command for each.

3. Read the graph and the table

  • The table on the right lists every function with self and total time (or samples) and both percentages; for gprof, also how many times each was called. Click a column header to sort, or type in Filter functions by name.
  • Select a row to see its callers and callees, each with its share. Double-click a caller or callee to move to it.
  • The flame graph on the left: click a frame to zoom, press Esc or click the root to zoom out. Icicle puts the root at the top. Type in Search frames to highlight a function and see its share of the total.
  • perf script and trace files with several threads get a thread and process selector; pprof files with several sample types get a sample-type selector.
  • For gprof the graph is estimated, and the tab says so: gprof records no call stacks, so each function's time is split among its callers using gprof's own call-graph estimates. The table shows gprof's numbers unchanged: seconds, calls, and its own % time columns as Self % (flat profile) and Total % (call graph).

4. Jump to source

Double-click, or press Enter on, a row or a frame.

  • When the profile records a file and line (pprof, gprof -l, perf script with srcline, trace events that carry them), the editor opens at that line.
  • Paths recorded on another machine, such as /home/ci/build/zlib/deflate.c, are matched to the project file with the longest common path suffix. When two files tie, Heatfold asks you to choose.
  • When the profile records only a name (a plain gprof report, perf script without srcline), Heatfold asks the IDE's Navigate | Symbol. So C and C++ names resolve in CLion; IntelliJ IDEA and PyCharm have no C support, so there use gprof -l or perf script -F +srcline. When a name does not resolve, the message line names that command.
  • When nothing matches, one line in the tool window says why.

Large files

Files are read in the background, with a progress bar and Cancel in the tab and in the status bar. What fits depends on how many distinct call paths a profile has, not only on its size: at the IDE's default 2 GB heap a 500 MB perf script with 20,000 distinct frames fits, and a larger file of a program with few call paths can too. A profile is refused, with a message, only when it would not fit in the memory the IDE can spare; raise the heap with Help | Change Memory Settings for larger files or more large tabs.

Licence and trial

$15 once, the same for personal and commercial use, with a 30-day trial of every feature. No free version, no subscription, nothing renews; updates are included. Like every paid plugin, Heatfold is licensed through the IDE's own dialog (see Install), and the trial needs a free JetBrains Account. Heatfold's own messages are two: if a trial ends while the IDE is running, the Heatfold tool window shows one line with a link to that dialog; and after your fifth profile one notification asks for a review, never again. The terms are in the licence agreement.

Known limits

  • Heatfold does not record, run or attach to a profiler.
  • Not read: folded or collapsed stacks, cProfile, JFR, V8 profiles.
  • No timeline view of trace events, no comparison of two profiles, no demangling (names are shown as the file writes them), no image or table export. English only.
  • Call paths deeper than 1,024 frames are cut there, and the tab says so.

Privacy

Heatfold makes no network calls and collects nothing: no telemetry, no analytics, no crash reports. It reads only the files you open and, for jump to source, the files of the open project. See also the privacy policy.
